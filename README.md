## ✨ Возможности

### 🎵 Музыкальный плеер
- Поиск по миллионам треков (SoundCloud)
- Кроссфейд, gapless, ReplayGain
- 10-полосный эквалайзер (12 пресетов)
- 3 визуализатора (волна, полосы, круг)
- Spatial Audio, Sleep timer, A-B повтор
- Синхронизированные тексты песен с переводом
- 25+ тем оформления

### 💬 Мессенджер
- Личные чаты и группы
- Голосовые сообщения с waveform
- Реакции, закрепление, ответы
- Stories (текст/фото/трек/видео)
- Кастомные темы чатов
- Поиск по сообщениям

### 📊 Профиль
- Достижения (10 бейджей)
- Тепловая карта прослушиваний
- Статистика, top артисты
- Taste Profile

### 🎨 Дизайн
- Glassmorphism
- Микро-анимации
- Command Palette (⌘K)
- PWA + Android + Desktop
- Полная доступность (a11y)

## 🛠 Технологии

Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · Framer Motion · Web Audio API · Turso · Capacitor · Electron
