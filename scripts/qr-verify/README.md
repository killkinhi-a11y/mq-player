# QR verification harness

`jsQR.js` — the official dist bundle of `jsqr@1.4.0` (https://github.com/cozmo/jsQR),
Apache License 2.0. Copyright (c) 2016 Cosby LLC. Used ONLY as a QR decoder for
offline verification that QR codes generated by `src/lib/qr.ts` really scan.

Run: `npx vitest run src/__tests__/lib/qr.test.ts` (decode round-trip included).
