## MQ Player 2.3.2 — Release Candidate (фикс краха «Демо»)

**Статус:** кандидат на релиз. Ожидает подтверждения на реальном Android-устройстве. Продакшн-канал сайта («Скачать приложение» → latest) продолжает отдавать 2.3.1, пока RC не подтверждён.

### Что исправлено

**Крах приложения при нажатии кнопки «Демо»** — воспроизведён и доказан в runtime (эмулятор AOSP 35, system_server жив, CrashDiagnostics зафиксировал):

```
java.lang.IllegalArgumentException: Unexpected char 0x414 at 0
  in x-demo-user-name value: Демо
```

Причина: кириллическое имя демо-пользователя отправлялось как значение HTTP-заголовка `x-demo-user-name`; OkHttp отвергает не-ASCII значения → неперехваченное исключение на dispatcher-потоке → смерть процесса.

Фикс: заголовок `x-demo-user-name` отправляется только при печатном ASCII-значении, иначе опускается — точный паритет с web-версией (бэкенд сам подставляет «Демо»). Тесты 157/157, включая wire-проверку реального перехватчика.
