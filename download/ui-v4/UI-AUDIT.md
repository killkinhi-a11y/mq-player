## 0. Инвентаризация поверхностей

**Реальные URL-маршруты**: `/` (лендинг→redirect), `/play` (SPA-шелл — главное приложение), `/track/[id]`, `/admin/*` (11 экранов), `/tg`, `/privacy`, `/terms`, `/desktop-auth`, `error.tsx`, `global-error.tsx`.

**Виды внутри SPA** (store-driven, playback переживает переключение — инвариант V4):
main · search · library (+playlists/favorites/history как табы) · messenger · settings · profile · public-playlists · stories · onboarding · spatial · friends · sleepTimer · auth.

**Глобальные оверлеи**: FullPlayer (Classic FullTrackView / FullTrackViewMobile / SpatialFullPlayer), PlayerBar-капсула, MobileDock, QueueView drawer, EqualizerView, CommandPalette (⌘K), NotificationPanel, ShareSheet, ContextMenu (MenuCore), OnboardingTour, UpdateBanner, MaintenanceBanner, OfflineBanner, SplashScreen, KeyboardShortcutsHelp, AudioDebugPanel (dev-only).

**Темы**: 25+ цветовых тем через `lib/themes.ts` + 8 «стилей» (`src/styles/*.css` — ipod-2001, japan, swag, neon, minimal, pixel-flower, streaming). Токены: `design-tokens.css` (зрелые) + `globals.css` 5127 строк.

## 2. Постраничный аудит

### Home / MainView (2462 строк)
- **Плюсы**: hero «Продолжить прослушивание» с реальными данными; аккордеон рекомендаций (v6/v7); chrome-streak artwork-band (v5).
- **Проблемы**: (а) приветствие+дата — контраст даты низкий; (б) «For You» — пустая широкая карточка в демо, без рамки/CTA, «сливается»; (в) секции одной приоритетности — нет ритма big/small; (г) быстрые карточки (Избранное/История/Плейлисты/Чаты) — «—» бейджи нулей выглядят сломанно; (д) зазор hero→секции не по сетке.
- **План**: типографическая лестница (display-приветствие → section → caption), ревизия сетки 12-col, empty-карточки с CTA, бейджи только при наличии данных, градиентный CTA hero.

### Search / SearchView (1436 строк)
- **Плюсы**: есть recent searches, suggestions, жанры, группировка, keyboard-nav — функционально сильно.
- **Проблемы**: (а) X1 красный фокус; (б) «Ничего не найдено» — огромная вертикальная «яма» (~150px) от инпута, заголовок и подсказка сливаются; (в) нет Top Result hero-карточки; (г) строки результатов без hover-artwork affordance.
- **План**: X1; сжать пустое состояние (заголовок 22–24px + быстрые ссылки-жанры как чипы-кнопки), Top Result при точном совпадении, единый TrackRow.

### PlayerBar (капсула) + MobileDock
- **Плюсы**: VLM — «сильнейший элемент», glass, скругления, spacing отличный.
- **Проблемы**: (а) X2 таймкоды; (б) таймкод прижат к полосе без «воздуха»; (в) mobile: «1 Issue» перекрывает навигацию (dev-only); (г) заголовок/артист не кликабельны (нет перехода на артиста/альбом).
- **План**: tabular-nums, микро-решётка капсулы, кликабельные артист/альбом (лёгкий hover), финальный polish.

### FullPlayer — FullTrackView (1663) / Mobile (1100) / Spatial (fullplayer/)
- **Плюсы**: кинематографичность, градиент от обложки, рамка обложки; Spatial — отдельная лига.
- **Проблемы**: (а) контент смещён влево, правая треть пустует (Classic); (б) hotkeys-подсказки 11px серые «второсортные»; (в) серые иконки действий низкого контраста; (г) дистанции: прогресс↔кнопки велики, кнопки↔иконки малы — слипание групп.
- **План**: центрирование композиции/баланс, hotkeys как капсулы-чипы, контраст-токен для иконок, пересборка вертикального ритма по шкале отступов.

### Queue / QueueView (1177)
- **Плюсы**: glass-модалка, разделы «Сейчас играет/Далее», перетаскивание.
- **Проблемы**: (а) drag-handle «6 точек» — тяжёлый, диссонанс с базовой линией текста; (б) пустое состояние пассивно (нет CTA «Добавить из библиотеки»).
- **План**: тонкий grip (2×3 точки → 1×4 точка/линии), empty + CTA, показ источника добавления.

### Library / LibraryView (245) + FavoritesView (1228) + HistoryView (869)
- **Проблемы**: (а) пустые состояния «сердце + текст» — базовые; (б) excess whitespace в пустоте — «недоделанность»; (в) фильтры видимы при пустом контенте; (г) табы смешивают виджеты (seg-control vs чипы).
- **План**: EmptyState v2 (карточка+CTA), отключение фильтров без данных, единый Tabs.

### Artist / ArtistDetailView (648)
- **Проблемы**: нет полноценного hero-ритма: компактно, но без визуальной «вибрации» обложки; related artists не выражены; разный визуальный уровень секций слабо считывается.
- **План**: двухуровневая композиция (gradient hero с доминантным цветом обложки → контент), Top Tracks с «показать ещё», related-ряд.

### Album / PlaylistView (1534)
- **Проблемы**: hero выше сгиба на мобиле; трек-лист без зебры/hover-play; различие user/system плейлистов слабое.
- **План**: компактный hero на мобиле (одной рукой), hover-play на строках, статусные бейджи плейлистов.

### Settings (1325)
- **Плюсы**: VLM — «Very Premium», master-detail, danger zone.
- **Проблемы**: (а) статичные элементы без hover; (б) профиль текстово-тяжёлый.
- **План**: микро-hover на элементах сайдбара, лёгкий градиент профиль-карточки. Ничего не ломать.

### Auth / AuthView (1950)
- **Проблемы**: (а) вход — первое впечатление, сегодня композиция функциональная, но не «дорогая»; (б) demo-режим визуально равноценен реальному входу.
- **План**: премиальная композиция входа (типографика, стекло, глубина), без изменения потоков.

### Mobile (390×844)
- **Плюсы**: VLM — «native and fluid», sticky header, таргеты ок.
- **Проблемы**: (а) X6; (б) пустая карточка «For You» сливается с фоном; (в) проверка 360×800 и 430×932 + safe-area не систематизирована.
- **План**: проход по всем видам на 3 размерах, safe-area фикс, hover→touch замена.

### Состояния
- Skeleton: есть (`Skeleton.tsx`), применяется не везде, где fetch.
- Error: ViewErrorBoundary есть; network-error в поиске есть. Retry — частично.
- Toast/уведомления: NotificationPanel есть.

## 3. Функциональные риски (не терять при редизайне)

1. Playback живёт вне React-вида (AudioEngine + store) — **никогда** не перерисовывать AppShell от progress-состояний.
2. `VISITED_VIEW_COMPONENTS` / `ViewTransition` — переключение видов без размонтирования (Messenger SSE). Не вводить AnimatePresence вокруг постоянных видов.
3. Lazy-импорты god-компонентов (bundle) — не вытягивать SettingsView/MessengerView в eager.
4. Мобильный back-button layering (popstate) — не ломать при новых оверлеях.
5. 565 тестов — не ослаблять; `npm test` зелёный обязателен.
6. 25 тем + 8 стилей — редизайн v4 делаем на уровне default-темы и общих токенов, остальные темы наследуют через переменные (не хардкодить цвета).
